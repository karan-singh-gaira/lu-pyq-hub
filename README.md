# LU PYQ Hub 📚

A fast, responsive, and organized web platform designed for Lucknow University students to easily access semester Previous Year Question Papers (PYQs) for various undergraduate and postgraduate streams.

🚀 Live Demo
- Website: https://melodious-stardust-3307cd.netlify.app/

 ✨ Key Features
- Clean UI/UX: Responsive card-based layout with Dark/Light mode toggle.
- Dynamic Resource Delivery: Integrated with structured Google Drive cloud storage.
- Search Engine Optimized: Configured with custom meta tags, `sitemap.xml`, and verified via Google Search Console.
- Fast Performance: Deployed and hosted live on Netlify.

 🛠️ Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Hosting & Deployment: Netlify
- Storage: Google Drive
- SEO & Indexing: Google Search Console
